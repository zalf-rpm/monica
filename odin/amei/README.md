# Generated Crop2ML packages

Odin code generated by PyCrop2ML's Odin target from the Crop2ML packages pinned in
`../versions.json` (`crop2ml`). **Never edit these files.** Fix problems in the Crop2ML package or
in PyCrop2ML, move the pins, and regenerate:

```bash
pixi run gen-amei
```

CI regenerates them and fails if anything changes. To add a package, list it under its source in
`versions.json`. MONICA uses a package only through a binding in
`../monica/modules/<process>/` (see `plan-crop2ml-modules.md`).
